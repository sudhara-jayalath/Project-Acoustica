# Project Acoustica — website (draft)

Draft homepage for **Project Acoustica**: from the underground, to the world.
Sessions · Academy · Records · Merch.

Live preview: https://sudhara-jayalath.github.io/Project-Acoustica/

Concept direction "Between the lines", built on Sagara Weerasinghe's statement:
https://sudhara-jayalath.github.io/Project-Acoustica/between-the-lines/

This is a work-in-progress design preview. Anything in `[BRACKETS]` is a placeholder,
and the forms are not connected yet. The page is set to `noindex` so search engines
don't list it before the official launch.

## Files

- `index.html` — the whole page (HTML + inline styles, no build step)
- `assets/` — logo mark, wordmark, hero lockup, favicon and link-preview image
- `assets/merch/` — merch mockups (props: tees, totes, posters)
- `between-the-lines/index.html` — concept page: pluckable strings that contain the chaos (canvas + Web Audio, no libraries)
